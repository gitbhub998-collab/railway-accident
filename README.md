# Railway Accidents & Disaster Readiness

A bilingual English and Arabic quiz for learning about railway accidents, disasters, and emergency response.

## Run locally

Open `index.html` in a browser, or serve the project folder with a local static server such as the VS Code Live Server extension.

## Project files

- `index.html` — quiz page and content structure
- `style.css` — responsive design and visual styling
- `script.js` — quiz data and interactions
- `Logo.jpg` — project logo
- `audio/` — success and failure sounds

## Deployment

This is a static website. It can be deployed with Vercel using the included `vercel.json`, or hosted from the repository root with GitHub Pages.
