# Railway accidents and disaster management

A bilingual English-Arabic quiz with 15 questions about railway accidents and disaster management.

## Run locally

Open `index.html` in a browser. This is a static site: it has no build step, package installation, or server-side requirements.

## Publish with GitHub Pages

1. Push the project files to the default branch of your GitHub repository.
2. In the repository, open **Settings > Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select the default branch and the `/ (root)` folder, then save.

All site assets use relative paths, so the site works from the repository root and a GitHub Pages project subpath.

## Deploy with Vercel

Import your GitHub repository into Vercel and deploy the project root. No build command is required; `vercel.json` serves the site files as static assets.
